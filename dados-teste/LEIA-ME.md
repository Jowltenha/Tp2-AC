# Dados sintéticos de pacientes

Dados **sintéticos**, mas com o formato real (nome, CPF, telefone). Não devem ir para o contexto do
Claude Code sem necessidade explícita: a pasta fica fora do diretório de trabalho da squad e só é
liberada com `claude --add-dir ../dados-teste` (ver `docs/ex05-diretorios.md`).
